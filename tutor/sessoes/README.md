# Sessões

Ainda não há sessão de estudo concluída. Crie arquivos `AAAA-MM-DD-NN.md` a partir do [modelo](../templates/sessao.md), sem sobrescrever outra sessão. Use uma sequência livre na data real.

Uma sessão registra o que aconteceu, não uma conversa inteira. Dados ausentes ficam como “não informado”. Atualize também o estado do tutor. Os arquivos precisam de commit e push para chegar à outra máquina.
